# notesAppByPower

A public notes and technical blogging platform, developed by a two-person Java team.

## Project documentation

- [Product and backend blueprint](docs/notesAppByPower-blueprint.md)
- [Blueprint PDF](docs/notesAppByPower-blueprint.pdf)

## Planned stack

Java 21, Spring Boot 3.5, Maven, MySQL and MongoDB. Independently deployable Catalog, Content and Media services; gateway and security introduced in later milestones. AWS deployment design is pending.

## Current status

Product planning and architecture baseline. Application code has not been implemented yet.

## First milestone

Set up Catalog Service, local MySQL, Flyway migrations and collection create/read APIs with validation and integration tests. Follow the blueprint for the remaining milestones.
